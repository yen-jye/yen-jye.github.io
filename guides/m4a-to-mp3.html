M4A to MP3 Converter

1. 사용 방법

  1. 파일 선택 — M4A 파일을 화면에 끌어다 놓거나 “Choose M4A Files”를 눌러 고릅니다. 여러 파일을 한 번에 넣을 수 있습니다.
  2. 음질 선택 — 128, 192, 256, 320kbps 중 하나를 고릅니다. 전체 기본값을 정하거나 파일마다 따로 바꿀 수 있습니다.
  3. 변환 — “Convert All to MP3”를 누르면 파일을 하나씩 차례로 변환하며 진행률이 표시됩니다. 진행 중에는 파일별 또는 전체 취소가 가능합니다.
  4. 확인과 다운로드 — 원본 M4A와 결과 MP3를 바꿔 가며 미리 들을 수 있고, 원본·결과 파일 크기와 재생시간이 표시됩니다. MP3를 하나씩 받거나 “Download All as ZIP”으로 한 번에 받습니다.

2. 음질(비트레이트) 고르기

  • 128kbps — 음성 메모, 강의, 회의 녹음. 1분에 약 0.96MB.
  • 192kbps — 팟캐스트, 일반 오디오(기본값). 1분에 약 1.44MB.
  • 256kbps — 음악. 1분에 약 1.92MB.
  • 320kbps — MP3 최대 음질. 1분에 약 2.4MB.

M4A(AAC)와 MP3는 모두 손실 압축 형식입니다. 원본에서 이미 사라진 소리는 높은 비트레이트로 변환해도 돌아오지 않고 파일만 커집니다. 원본 음질에 맞는 값을 고르세요. 변환된 MP3는 선택한 값의 고정 비트레이트(CBR)입니다.

3. 지원 코덱

M4A는 여러 코덱을 담을 수 있는 그릇(컨테이너)입니다. 도구는 변환 전에 파일 안의 코덱을 확인하고, 변환할 수 없으면 파일별로 이유를 알려 줍니다.

  • AAC(대부분의 M4A) — 최신 Chrome, Edge, Safari, Firefox에서 변환됩니다.
  • Apple Lossless(ALAC) — 브라우저마다 다릅니다. Chrome 계열에서는 실패할 수 있고, Apple 기기의 Safari를 권장합니다.
  • Opus·FLAC(M4A 안에 든 경우) — Chrome 계열에서 변환을 확인했으며 다른 브라우저는 다를 수 있습니다.
  • 변환 불가 — Dolby Digital(AC-3/E-AC-3), DRM 보호 파일(구형 iTunes 구매곡 .m4p), 오디오가 없는 영상 파일, 손상된 파일. 각각 원인을 안내합니다.

4. 긴 녹음과 기기 메모리

파일 크기 제한은 없지만, 브라우저가 녹음 전체를 메모리에 풀어 놓은 뒤 MP3로 인코딩합니다. 스테레오 기준 1분에 약 21MB, 1시간 녹음은 약 1.3GB의 메모리가 필요합니다. PC에서는 대체로 문제가 없지만 휴대폰에서는 긴 녹음 변환 중 탭이 닫힐 수 있습니다. 이럴 때는 PC에서 변환하거나 녹음을 나눠 주세요.

6. 자주 묻는 질문

확장자만 바꾸는 건가요?
아니요. 오디오를 디코딩한 뒤 LAME 기반 인코더(lamejs, LGPL-3.0)로 실제 MP3를 새로 만듭니다.

MP3가 원본보다 커졌어요.
음성 메모는 보통 낮은 비트레이트로 저장됩니다. 더 높은 비트레이트를 고르면 MP3가 커질 수 있으니 음성은 128kbps를 권장합니다.
